# First-Time User Usability Checklist

## Application Access
- [ ] Application starts successfully.
- [ ] Main menu is displayed clearly.
- [ ] Menu options are understandable.

## Train Search
- [ ] User can enter source and destination.
- [ ] User can enter a journey date.
- [ ] Matching trains are displayed.
- [ ] No-result messages are understandable.

## Booking
- [ ] User can select a train.
- [ ] Seat availability is displayed.
- [ ] Passenger details can be entered.
- [ ] Invalid inputs show helpful messages.

## Error Handling
- [ ] Empty inputs are handled.
- [ ] Invalid dates are rejected.
- [ ] Invalid selections are rejected.

## Evaluation Notes

Record observations during an actual first-time-user walkthrough.

Do not mark a scenario as passed until it has been manually tested.
